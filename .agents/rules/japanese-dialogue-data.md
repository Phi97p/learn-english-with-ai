# Rule: Nguồn Dữ Liệu Tab Hội Thoại Tiếng Nhật

## Quy định
- Dữ liệu nguồn cho **Tab Hội thoại tiếng Nhật** được đặt trong thư mục: `datasss/jp/hoi_thoai/`.
- Khi cần cập nhật hoặc nạp bài học hội thoại tiếng Nhật mới (cho 2 người nói / đóng vai với AI), AI sẽ đọc các file trong thư mục này (ví dụ: `bai_1.txt`, `bai_2.txt`,...) để phân tích, phiên âm Romaji, nghĩa tiếng Việt, phân vai nhân vật và nạp vào `JA_DIALOGUE_DATA` trong `japanese_data.js`.
