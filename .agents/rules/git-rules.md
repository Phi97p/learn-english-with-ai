# Rule: Quy Định Git

## Quy định
- **Tuyệt đối KHÔNG BAO GIỜ thực hiện lệnh `git push`** lên remote repository trong mọi trường hợp.
- **KHÔNG TỰ ĐỘNG COMMIT**: Tuyệt đối không tự ý chạy lệnh `git commit` sau mỗi lần chỉnh sửa. Chỉ khi nào người dùng có yêu cầu cụ thể (ví dụ: "commit đi", "hãy commit",...) thì AI mới được phép thực hiện commit.
