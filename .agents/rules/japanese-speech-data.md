# Rule: Nguồn Dữ Liệu Tab Luyện Nói Tiếng Nhật

## Quy định
- Dữ liệu nguồn cho **Tab Luyện nói tiếng Nhật** được đặt trong thư mục: `datasss/jp/luyen_noi_jp/`.
- Khi cần cập nhật hoặc nạp bài học luyện nói tiếng Nhật mới, AI sẽ đọc các file trong thư mục này (ví dụ: `bai_1.txt`, `bai_2.txt`,...) để phân tích, phiên âm Romaji, nghĩa tiếng Việt và cập nhật vào `JA_SENTENCE_UNITS_DATA` trong `japanese_data.js`.
